# PCSS CHESS CLUB PAIRINGS WEBSITE
## Website Featurs
1. Home page displays parirings
2. Update page diplays player stats for the rosters
3. Update page also allows you to generate pairings
4. Roster page allows you to add and change rosters
5. Roster page allows you to switch between rosters 
6. History page shows you history for selected roster
## Pairings Features
1. First round based on elo 
2. Players switch colors every round
3. Prevents repeat matchups
4. Deal with odd number of players giving 1 player bye
5. Accounts for wins, draws, both exused and unexcused absences, and byes
6. player rank determined by points or elo incase of tie
## Rules for BYEs
1. Players who have not had byes before are chosen
2. Player with lowest points in tournament is chosen
3. If points are the same then player with lowest elo is given bye
4. Logic is that giving players at the bottom byes will not affect the top ranking and people who will acc get selected
